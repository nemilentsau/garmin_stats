## 1. Design Principles

1. **Everything serves running.** Stretching opens the mechanics. Breathwork builds autonomic recovery. Core builds efficiency under fatigue. All periodized around the training that matters most.
2. **Periodized by training load.** Hard days minimize volume and cognitive demand. Easy days invest in skill development and deep mobility. Rest days push the edges.
3. **Morning stack has a fixed order.** Stretching → Breathwork → Core → Supporting → Run. Each component feeds the next.
4. **Core rotation is load-independent.** A-B-C-D advances daily regardless of training type. Volume adjusts, sequence never breaks.
5. **Supporting muscle work lives on easy/rest days only.** Hard days already tax these systems.
6. **HRV is the objective test.** Morning rMSSD (Garmin Epix Pro Gen 2) measures whether this system actually works. No fake scores, no vibes.
7. **Three daily slots.** Morning (physical + autonomic priming), midday (attentional reset), evening (recovery/skill). Each slot has a distinct purpose.

## 2. Morning Stack Order

```
1. STRETCHING               10-15 min
   Opens thoracic spine → improves breathing quality for breathwork
   Opens hips → warms patterns for core work and running

2. BREATHWORK                10-12 min
   Autonomic priming (Resonance/CO2)
   Transitions from passive stretching to active work

3. CORE ROTATION             10-15 min
   Trunk stabilizer activation before running
   Functions as dynamic warm-up for run

4. SUPPORTING MUSCLE WORK    0-25 min (easy/rest days only)
   Glutes, calves, hip flexors, nordics
   Pre-run prehab on easy days, full sessions on rest days

5. RUN
```

**Why this order:** Thoracic stretching immediately before resonance breathing means each breath can access the range you just opened. Core activation before running means trunk stabilizers are "on" from stride one. Supporting work is prehab that primes the specific muscles running loads hardest.

## 3. Protocol & Exercise Reference

### 3a. Breathwork & Meditation Protocols

| Protocol | Pattern | Duration | Primary Target |
|----------|---------|----------|----------------|
| Resonance Breathing | 5s in / 5s out (~6 bpm) | 10-12 min | Vagal tone, baroreflex training |
| Extended Exhale | 4s in / 7s out | 8-10 min | Parasympathetic activation, recovery |
| Box Breathing | 4s in / 4s hold / 4s out / 4s hold | 6-8 min | Arousal control, composure |
| CO2 Tolerance | 4s in / 6s out / 4s post-exhale hold | 10 min | CO2 comfort threshold |
| Focused Attention | Breath counting or single-point | 10-15 min | Concentration stability |
| Open Monitoring | Non-directive awareness | 15 min | Interoceptive clarity, non-reactivity |

**Post-session logging (all sessions):** Attention stability (1-5), relaxation depth (1-5), mental clarity (1-5). Target <15 seconds to complete.

### 3b. Stretch Library — Shoulders & Hips

**Why these two areas:** Tight pecs/anterior shoulders from desk work → kyphosis → compressed ribcage → limited diaphragm excursion → throttled breathwork quality. Tight hip flexors from sitting + running → anterior pelvic tilt → killed glute activation → degraded running mechanics.

#### Shoulder & Thoracic Openers

| ID | Stretch | Target | Hold / Reps | Cues |
|----|---------|--------|-------------|------|
| S1 | Thread the needle | Thoracic rotation, posterior shoulder | 30s each side | All fours, slide arm under, shoulder to floor. Breathe into the rib expansion. |
| S2 | Open book | Thoracic rotation, pec, anterior shoulder | 30s each side | Side-lying, knees stacked 90°. Top arm opens toward opposite side. Follow hand with eyes. |
| S3 | Wall slides (CARs) | Shoulder flexion, upward rotation, serratus | 8-10 reps | Back flat on wall, arms in goal post, slide overhead. Low back lifts = too far. |
| S4 | Doorway pec stretch | Pec major/minor, anterior deltoid | 30s each side | Forearm on frame at 90°, step through. Low elbow = upper pec, high = lower. Do both. |
| S5 | Cat-cow | Thoracic flexion/extension, spinal segmentation | 10 slow reps | Initiate from pelvis, not neck. Exhale fully into cat. |
| S6 | Prone Y-T-W raises | Lower trap, rotator cuff, scapular stability | 8 reps each position | Face down, lift hands 2" off floor, hold 3s. Thumbs up. Activation, not stretch. |
| S7 | Cross-body shoulder stretch | Posterior deltoid, infraspinatus | 30s each side | Arm across chest. Keep shoulder down, don't hike toward ear. |
| S8 | Foam roller thoracic extension | Thoracic extension, rib cage expansion | 60s | Lengthwise on roller, arms fall open, palms up. Best position for opening breathing mechanics. |

#### Hip Openers

| ID | Stretch | Target | Hold / Reps | Cues |
|----|---------|--------|-------------|------|
| H1 | 90/90 hip switches | Internal/external rotation, deep rotators | 10 reps | Both knees 90°, rotate side to side. Spine tall, no leaning. |
| H2 | Pigeon / figure-4 supine | Piriformis, external rotators, glute | 45s each side | Figure-4 if pigeon bothers the knee. Don't force depth. |
| H3 | Half-kneeling hip flexor | Psoas, rectus femoris, anterior hip capsule | 45s each side | Squeeze rear glute to posteriorly tilt pelvis BEFORE leaning forward. |
| H4 | Frog stretch | Adductors, medial hip capsule | 45s | All fours, widen knees, feet out. Rock gently forward/back. |
| H5 | Supine spinal twist | Hip rotators, thoracolumbar fascia, obliques | 30s each side | Knee across body, opposite shoulder on floor. Gravity does the work. |
| H6 | Hip CARs | Full hip ROM, capsular health | 5 each direction, each side | Standing, biggest circle with free knee. Slow and controlled. |
| H7 | Couch stretch | Rectus femoris, psoas (deep) | 45s each side | Rear foot on couch/wall. Squeeze rear glute. Most aggressive hip flexor stretch. |
| H8 | Adductor rockback | Adductors, medial hamstring | 30s each side | Half-kneeling, one leg straight to side. Rock hips back toward heel. |

### 3c. Core Rotation (4-Day Cycle: A → B → C → D)

Advances daily regardless of training type. Volume adjusts by day type.

#### Day A — Rotation Focus
| Exercise | Full Dose | Reduced (Hard Day) |
|----------|-----------|-------------------|
| Cable rotations (horizontal) | 3×10 each side | 2×10 each side |
| Pallof press + overhead reach | 3×8 each side | 2×8 each side |
| Dead bugs | 2×10 each side | 2×8 each side |
| Plank shoulder taps | 2×12 each side | Drop |

#### Day B — Anti-Extension Focus
| Exercise | Full Dose | Reduced (Hard Day) |
|----------|-----------|-------------------|
| Ab wheel rollouts | 3×10 | 2×8 |
| Hanging leg raises | 3×12 | 2×10 |
| Body saw plank (sliders) | 3×8 | 2×6 |
| Hollow body hold | 2×30s | Drop |

*On incline press days, cut Day B in half or skip — already getting anti-extension under heavy load.*

#### Day C — Oblique & Lateral Focus
| Exercise | Full Dose | Reduced (Hard Day) |
|----------|-----------|-------------------|
| Cable rotations (high-to-low woodchop) | 3×10 each side | 2×10 each side |
| Copenhagen plank | 2×20s each side | 2×15s each side |
| Suitcase carry | 2×30m each side | Drop |
| Side plank + hip dip | 2×10 each side | 2×8 each side |

#### Day D — Dynamic / Power
| Exercise | Full Dose | Reduced (Hard Day) |
|----------|-----------|-------------------|
| Cable rotations (low-to-high) | 3×10 each side | 2×10 each side |
| Hanging windshield wipers | 3×8 | 2×6 |
| Med ball slams | 3×10 | 2×8 |
| Turkish get-up | 2×3 each side | Drop |

**Intensity guideline:** RPE 6-7, never to failure. The goal is cumulative volume and motor pattern reinforcement, not hypertrophy. Heavier/slower on rest days, lighter/quicker on hard days.

| Single-leg glute bridge | 2×12 each side |

#### Block 2 — Lower Leg & Foot (~8 min)
| Exercise | Sets × Reps |
|----------|-------------|
| Heavy slow calf raises (straight leg) | 3×8 |
| Bent-knee calf raises (soleus) | 3×10 |
| Tib raises | 2×15 |
| Short foot / single-leg balance | 2×30s each side |

#### Block 3 — Eccentric / Reactive Stiffness (~8 min)
| Exercise | Sets × Reps |
|----------|-------------|

| Single-leg RDL | 2×8 each side |

**Easy days:** Do 2 of 3 blocks, rotate which one you skip. **Rest days:** All 3 blocks.

## 6. Progression System

### Phase 1: Foundation (Weeks 1-4)

**Goal:** Establish consistency and collect baseline data.

| Component | Target |
|-----------|--------|
| Stretching | Use prescribed hold times. Log which stretches feel most restricted. |
| Breathwork | >80% session compliance. Establish 3x/day habit. |
| Meditation | Focus on logging quality ratings consistently. |
| Core | Establish rotation at prescribed volumes. Focus on form and controlled tempo. |
| Supporting | Establish 2-3 sessions/week on easy/rest days. |

### Phase 2: Extension (Weeks 5-8)

**Goal:** Increase volume on what's working, identify top HRV correlations.

| Component | Progression |
|-----------|-------------|
| Stretching | Increase holds to 60s on 2-3 tightest stretches. Add second set on most restricted hip pattern. Make foam roller thoracic extension (S8) daily regardless of template. |
| Breathwork | If HRV trend positive: extend Extended Exhale to 12 min. If flat: personalize resonance frequency (test 5.5s, 6s, 6.5s cycles). |
| Meditation | Increase Focused Attention to 15 min on easy days. Add body scanning to Open Monitoring. |
| Core | Add load: cable rotations +5 lbs, ab wheel knees → standing, hanging leg raises → L-sit, carries +10 lbs, TGU +5 lbs. |
| Supporting | Calves: bodyweight → loaded (dumbbells). Nordics: band-assisted → full range. Glute medius: floor → standing cable abduction. |

### Phase 3: Optimization (Weeks 9+)

**Goal:** Double down on protocols showing strongest signal, cut noise.

| Component | Progression |
|-----------|-------------|
| Stretching | Add loaded mobility: KB overhead on hip flexor stretch, active pigeon (lift/lower torso), resistance band on wall slides. |
| Breathwork | Double down on protocols with strongest HRV correlation. Reduce/eliminate those showing no signal. Experiment with CO2 Tolerance on easy days. |
| Meditation | Extend Open Monitoring to 20 min if attentional stability ratings are consistently >4/5. |
| Core | Add complexity: dead bugs + band, hollow rocks, Copenhagen + top-leg movement, Pallof press with rotation. |
| Supporting | Soleus raises → 5s eccentrics. Nordics → add load (plate to chest). Single-leg squat variations. |

## 7. HRV Experiment Protocol

### Measurement

- **Instrument:** Garmin Epix Pro Gen 2 morning HRV (rMSSD-based)
- **Timing:** Take HRV reading at consistent time each morning, ideally AFTER morning breathwork (document the order)
- **Minimum data:** 4-6 weeks of consistent protocol for meaningful trend analysis
- **Baseline:** Capture 2+ weeks of morning HRV before starting as comparison

### Primary Correlations

| Independent Variable | Dependent Variable | Hypothesis |
|---------------------|-------------------|------------|
| Evening Extended Exhale (yes/no) | Next-morning HRV | Positive correlation |
| Hard day + Extended Exhale vs hard day alone | Next-morning HRV delta | Faster recovery with breathwork |
| Weekly 3x/day compliance (%) | 7-day rolling HRV average | Higher compliance → upward trend |
| CO2 Tolerance sessions (count/week) | Weekly HRV variance | May reduce volatility |
| Midday Focused Attention rating | Same-evening Open Monitoring depth | Attentional training transfers |
| Thoracic stretching before breathwork | Breathwork relaxation_depth rating | Better mobility → deeper breathing |
| Core session compliance (daily) | Pace:HR ratio on easy runs | Consistent core → better economy |
| Supporting work compliance (weekly) | Injury incidence / pain log | More work → fewer niggles |
| Morning core activation before hard run | Run quality (subjective 1-5) | Pre-run activation → better late-workout form |
| Nordic curl volume (weekly sets) | Post-long-run hamstring soreness | More nordics → less soreness |
| Hip stretching compliance (weekly) | Post-long-run hip/glute soreness | Consistent mobility → less tightness |

### Secondary Correlations

| Independent Variable | Dependent Variable |
|---------------------|-------------------|
| Evening session type (Extended Exhale vs Open Monitoring) | Sleep efficiency |
| Morning Resonance duration (10 vs 12 min) | Same-day RHR trend |
| Pre-race Box Breathing compliance | Race-day HRV morning reading |
| Training load + breathwork interaction | 48-hour HRV recovery slope |
| Foam roller thoracic extension before Resonance | Post-session HRV (if measurable) |

### Confound Controls (Log Daily)

- Training load (rest / easy / moderate / hard / race)
- Sleep duration and efficiency
- Alcohol (yes/no + amount)
- Evening carb load (none / low / moderate / high)
- Travel / timezone changes
- Caffeine timing (last intake time)
- Subjective stress (1-5)

## 8. Travel Adaptation (Costa Rica / Panama)

### Minimum Viable Morning Stack (~23 min)

```
1. Stretching (bodyweight essentials)              8 min
   - Cat-cow (S5): 8 reps
   - Half-kneeling hip flexor (H3): 30s each side
   - 90/90 switches (H1): 8 reps
   - Open book (S2): 30s each side
   - Supine spinal twist (H5): 20s each side

2. Resonance Breathing                            10 min

3. Core (bodyweight, no equipment)                10 min
   - Dead bugs: 3×10 each side
   - Plank shoulder taps: 3×12 each side
   - Side plank + hip dip: 2×10 each side
   - Hollow body hold: 2×30s

4. → Run
```

### Minimum Viable Supporting Work (every other day, ~8 min)

- Single-leg glute bridge: 3×12 each side
- Single-leg calf raises (on a step): 3×10 each leg
- Nordic curls (feet under bed frame): 2×5
- Tib raises: 2×15
- Single-leg balance: 2×30s each side

### Breathwork/Meditation (Protect 2 of 3 Slots)

1. Morning: Resonance Breathing 10 min — always
2. Evening: Extended Exhale 8 min — always
3. Midday: first to drop

### What You Lose Without a Gym

| Gym Exercise | Travel Substitute |
|-------------|-------------------|
| Cable rotations | Band rotations (pack a resistance band) |
| Ab wheel rollouts | Plank walkouts or inchworms |
| Suitcase carry | Single-arm overhead carry with backpack |
| Hanging leg raises | Lying leg raises |
| Copenhagen plank | Same (no equipment needed) |
| Heavy calf raises | Single-leg on a step (bodyweight) |

### Pack List

One loop resistance band. That's it.

### Logging

Tag travel days separately in the app. Maintain session timing relative to sleep/wake, not clock time.

### UI/UX Principles

1. **Mobile-first.** Primary interaction at the gym or pre-run.
2. **Minimal taps to log.** Default "completed as prescribed" — expand only for modifications.
3. **Today view is the main screen.** Shows stretch template, core rotation, supporting blocks, breathwork/meditation — all in one scrollable view.
4. **Sections collapse after completion.** Finished stretching → section collapses → breathwork expands.
5. **Exercise swap is one tap.** Show alternatives from variation group as bottom sheet.
6. **Session timers built in.** Breathing cues for breathwork, countdown for meditation, hold timers for stretches.
7. **No fake scores.** No "wellness score," no streaks, no gamification. Only show measured or self-reported data.
8. **Fast logging.** Post-session ratings <15 seconds. Post-stretch tightness log weekly, not daily.
9. **Dark mode default.** For evening use.
10. **Calendar view for history.** Color-coded: stretch done, core done, breathwork done, meditation done, supporting done.

### Analytics Dashboard

**Individual Metrics Over Time:**
- Session frequency by type (stretch, breathwork, meditation, core, supporting)
- Average ratings by session type
- Duration trends and compliance percentages

**Correlation Analysis:**
- Scatter plots and correlation coefficients for all pairs in the HRV experiment table
- Rolling 7-day and 30-day averages for key metrics
- Trend indicators (improving / stable / declining)
- Statistical significance flags (highlight correlations reaching p<0.05)

**Weekly Summary Auto-Report:**
- Compliance by category
- HRV trend vs. prior week
- Any exercises frequently skipped (signals boredom → suggest swaps)
- Tightness trend (improving/worsening by body area)
