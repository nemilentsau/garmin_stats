# HRV Tab v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the HRV tab's three inconsistent lifetime baselines with one trailing, user-tunable (30/60/90-day) robust baseline rendered as a moving ribbon + extreme-night markers, and remove the charts that answer no question (overnight trace, week-to-week box plot).

**Architecture:** A single backend primitive `trailing_robust_band` computes, per night, a robust normal range (`median ± 1σ` via MAD) and a z-score from the *prior* N present nights. Both HRV endpoints (`/analysis` for the trend series, `/insights` for the selected-day baseline) take a `baseline` window param and feed off that one primitive. The frontend gains a window knob (URL-persisted) that refetches; the trend chart draws the ribbon + markers; the selected-night panel reports a trailing z instead of a lifetime percentile.

**Tech Stack:** Backend FastAPI + numpy, Python 3.14 (uv). Frontend SvelteKit 2 / Svelte 5 runes / TS 5 / Chart.js (via `LineChart`/`BarChart` wrappers). Types flow Pydantic → OpenAPI → generated `frontend/src/lib/api-types.ts`.

## Global Constraints

- Python: `uv` only. Backend lint `uv run ruff check`, types `uv run pyright app/ tests/`, tests `uv run pytest tests/ -v` — all must pass with 0 errors before each backend commit.
- Frontend: `cd frontend && npm run check` must pass with 0 errors before each frontend commit.
- API types are generated, never hand-written: after any backend schema change run `bash scripts/generate-api-types.sh` and commit `frontend/src/lib/api-types.ts`.
- Frontend is display-only: zero statistical computation. All stats/baselines/deltas come from the backend. Array lookup + slicing for display is allowed; arithmetic transforms are not.
- Period-level stats come from raw/per-night values, never from averaging daily aggregates.
- Baseline definition constants (one source of truth): default window **60**, presets **30 / 60 / 90**, min present nights to render **21**, band half-width **k=1.0 σ**, extreme threshold **|z| > 2.0**. Robust scale = `MAD × 1.4826` (reuse `robust_center_scale`).
- Visual verification is non-negotiable: every changed surface must be screenshotted and confirmed in the running app before the work is considered complete.
- The recovery score core (`domain/recovery_score/`) is OUT OF SCOPE and must not change.

```python
# add to the existing `from app.utils.numeric import (...)` block:
#     robust_center_scale,

BASELINE_WINDOW_DEFAULT = 60
BASELINE_MIN_DAYS = 21
BASELINE_K_SIGMA = 1.0
BASELINE_Z_EXTREME = 2.0


@dataclass(frozen=True, slots=True)
class TrailingBandPoint:
    """Trailing robust baseline at one series index.

    Fields are all ``None`` (and ``is_extreme`` False) when the trailing window
    holds fewer than the minimum present values, so callers can render an
    explicit insufficient-data state instead of a misleading band.
    """

    band_low: float | None
    band_high: float | None
    median: float | None
    z: float | None
    is_extreme: bool


def trailing_robust_band(
    values: list[float | None],
    *,
    window: int,
    min_days: int,
    k_sigma: float = BASELINE_K_SIGMA,
    z_extreme: float = BASELINE_Z_EXTREME,
) -> list[TrailingBandPoint]:
    """Per-index robust normal range from the trailing ``window`` present values.

    For each index the band is built from present values in the half-open
    trailing window ``[i - window, i)`` (current value excluded, matching the
    recovery core's prior-only convention). Indices whose trailing window holds
    fewer than ``min_days`` present values yield an empty ``TrailingBandPoint``.
    """
    out: list[TrailingBandPoint] = []
    for i in range(len(values)):
        prior = [v for v in values[max(0, i - window):i] if v is not None]
        if len(prior) < min_days:
            out.append(TrailingBandPoint(None, None, None, None, False))
            continue
        median, scale = robust_center_scale(prior)
        low = round(median - k_sigma * scale, 1)
        high = round(median + k_sigma * scale, 1)
        current = values[i]
        if current is None:
            out.append(TrailingBandPoint(low, high, round(median, 1), None, False))
            continue
        z = (current - median) / scale
        out.append(
            TrailingBandPoint(low, high, round(median, 1), round(z, 2), abs(z) > z_extreme)
        )
    return out
```

```python
def _compute_baseline(
    metrics: list[DailyMetric],
    selected_index: int,
    baseline_7d: float | None,
    window: int,
) -> HrvBaseline | None:
    """Selected-day comparison against its trailing robust baseline."""
    nightly = [m.hrv.nightly_avg for m in metrics]
    band = trailing_robust_band(nightly, window=window, min_days=BASELINE_MIN_DAYS)
    point = band[selected_index]
    if point.median is None:
        return None
```
